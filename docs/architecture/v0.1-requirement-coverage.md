# v0.1 requirement coverage

This document maps executable behavior to the v0.1 source requirements. A package directory or
vocabulary term alone does not count as implemented behavior.

## Implemented behavior

| Requirement                 | Implementation and verification                                                                                                                                                     |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-001 / FR-002             | CLI imports Markdown, JSON, or text into SHA-256 content-addressed storage with idempotent duplicate detection.                                                                     |
| FR-003 / FR-004             | Approved Preference Assertions can be superseded, disputed, or retracted. Half-open temporal queries preserve superseded and retracted historical state.                            |
| FR-005                      | Assertion explanation resolves its Evidence and original source metadata.                                                                                                           |
| FR-006                      | Decisions record options, criteria, rationale, constraints, state snapshots, Outcome, and retrospective.                                                                            |
| FR-007                      | SQLite search combines structured temporal/privacy/status filtering with FTS5 lexical retrieval. Semantic retrieval is optional and not implemented.                                |
| FR-008                      | Context Builder applies query, time, privacy, Evidence expansion, and a deterministic token budget.                                                                                 |
| FR-009–FR-011               | One `LlmPort` supports Mock, native Ollama, native llama.cpp, and OpenAI adapters. Router fallback and P3 local-only policy are tested.                                             |
| FR-012 / FR-013             | Agents and users create pending Proposals; only human approve/edit writes a canonical Assertion. Reject writes no Assertion.                                                        |
| FR-014–FR-016               | Decision Simulator generates from a Context Pack, abstains without relevant Evidence, and returns deterministic counter-evidence for conflicting active Assertions.                 |
| FR-017–FR-019               | Current/historical Preference state and recent Decisions are queryable; a deterministic Personal Master Document view can be generated.                                             |
| FR-021                      | Framework-neutral HTTP handler exposes current state, search, provenance, Context Pack, simulation, and Proposal review.                                                            |
| FR-020                      | MCP stdio server exposes current state, search, provenance, Context Pack, and local Ollama-backed simulation tools.                                                                 |
| FR-022 / FR-023             | Canonical mutations retain actor, time, operation, reason, and Evidence IDs; all SQLite projections rebuild from events.                                                            |
| FR-024                      | Executable gold dataset contains exactly 100 cases: Fact 30, Temporal 20, Preference 20, Decision 20, Abstention 10.                                                                |
| FR-025 / NFR-008            | Agent Run records include provider/model, prompt version, Context IDs, latency, token usage, estimated cost, output, result, and failure. JSONL, in-memory, and D1 recorders exist. |
| NFR-003 / NFR-011           | P3 never reaches a remote provider; lexical/structured retrieval remains available with no LLM or embedding service.                                                                |
| NFR-004 / NFR-005           | Raw object hashes are verified; versioned backups restore Raw Evidence and Events into an empty store and rebuild projections.                                                      |
| NFR-006 / NFR-007 / NFR-012 | Application dependencies are ports; Clock/ID are injected; Vite+ enforces Domain dependency rules and cycles.                                                                       |
| NFR-013                     | SQLite and backup formats carry explicit schema version 1; unknown SQLite or backup versions fail closed.                                                                           |

## Ontology coverage

`ontology/personal-os-v0.1.jsonld` versions the vocabulary, gives every class/property a definition,
and records domain/range expectations. `ontology/competency-questions.md` maps CQ-01 through CQ-10
to relations and executable data, explicitly identifying vocabulary-only areas. The ontology remains
separate from the Domain and persistence schemas.

## Post-v0.1 / v1 candidates

- Semantic retrieval/reranking, richer contradiction detection, and a separate Critic agent.
- Encrypted/off-device backup transport, secret-store integration, privacy purge, and operational
  retention policy. Canonical export/restore is implemented; key management is intentionally not.
- Executable Goal, Project, Artifact, ResearchTopic, and graph projections. These currently exist in
  the ontology vocabulary only.
- Production Cloudflare/AWS provisioning, identity enrollment, policy configuration, and remote
  migration execution. Both cloud bundles and adapter contracts are executable, but account
  resources remain operator owned.
